## 🔐 Featured Cybersecurity Project

### CRYPTOCHECK — Cryptographic Security System

**CryptoCheck** is my Semester 7 MDM Minor CyberSecurity project focused on practical cryptographic security for files and passwords.

The system combines:

* 🔒 **Secure File Encryption & Decryption** using AES-GCM
* 🛡️ **File Integrity Verification** using SHA-256
* 🔑 **Password-Based Key Derivation** using PBKDF2-SHA256
* 📊 **Password Strength & Entropy Analysis**
* 🖥️ **Desktop GUI** for performing security operations
* 📝 **Activity Logging** for security-related operations

The project is designed to demonstrate how cryptographic techniques can be combined into a practical security application for protecting sensitive files and verifying their integrity.

**Project:** `CryptoCheck`

> **CRYPTOCHECK: A CRYPTOGRAPHIC SECURITY SYSTEM FOR SECURE FILE PROTECTION, INTEGRITY VERIFICATION AND PASSWORD SECURITY ANALYSIS**
